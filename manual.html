ずんだもんカフェ 編集画面 マニュアル

サイトの中身は、コードを触らずにこの画面から書き換えられます。この文書だけ読めば一通り操作できます。

1. これは何か

ずんだもんカフェの公式サイトは、表示する内容（開催情報・スタッフ・年表など）を content フォルダの中のデータファイルから読み込んで表示しています。

編集画面（admin/panel.html）は、そのデータファイルをフォームで書き換えて、 そのままサイトに反映するための道具です。HTMLやプログラムを触る必要はありません。

2. 最初の一回だけ：アクセストークンを作る

編集画面がサイトのデータを書き換えるには、GitHubの「アクセストークン」という鍵が要ります。 これは最初の一回だけ作れば、あとはそのブラウザに保存されます。

  1. GitHubにログインし、右上のアイコン →「Settings」を開く
  2. 左メニューをいちばん下までスクロールし、「Developer settings」を開く
  3. 「Personal access tokens」→「Tokens (classic)」を開く
  4. 「Generate new token」→「Generate new token (classic)」を押す
  5. Note（メモ欄）に zundacafe site と入れる
  6. Expiration（期限）を選ぶ
  7. スコープ（権限）は repo にだけチェックを入れる。他は触らない
  8. いちばん下の「Generate token」を押す
  9. 表示された文字列（ghp_ で始まる）をコピーする

注意

トークンは作った直後の一回しか表示されません。 画面を閉じると二度と見られないので、その場でコピーして編集画面に貼り付けてください。 見失ったら作り直せば大丈夫です。

トークンは他人に見せないでください。 これがあれば誰でもサイトを書き換えられます。

3. ログインする

  1. 編集画面（admin/panel.html）をブラウザで開く
  2. コピーしたトークンを貼り付けて「ログイン」を押す

以後、同じブラウザなら自動でログインした状態になります。 別のパソコンやスマホで使うときは、そちらでもう一度貼り付けてください。

やめたいときは右上の「ログアウト」を押すと、そのブラウザから鍵が消えます。

4. 各画面でできること

開催情報

次回の開催日、グループのURL、お知らせ、記念イベントの設定をします。

基本開催日隔週の起点になる日を1つ入れます。ここを毎回書き換える必要はありません。
開催間隔（日数）隔週なら 14 です。
開始時刻通常は 21:00。
臨時開催日（上書き）いつもの周期を無視して別の日にやるときだけ入れます。終わったら空欄に戻してください。
休止する回（日付）お休みする回の日付を足します。その回は自動で飛ばして、次の回が表示されます。
VRChatグループURLトップページの「グループに参加する」ボタンの行き先です。ここが空だとボタンが押せません。
お知らせチェックを入れると、トップページに一言だけお知らせの帯が出ます。
記念イベント第100回などの特設ブロックです。開催後は「開催後の文章」に書いた内容へ自動で切り替わります。

次回開催日は自動で計算されます

「基本開催日」から「開催間隔」ずつ数えて、今日より後で最初に来る日を自動で表示します。 毎回手で書き換える必要はありません。 お休みする回だけ「休止する回」に足してください。

スタッフ

店員さんの紹介です。役割・名前・自己紹介・アイコン画像を編集できます。

退任した人は「削除」しないでください

「表示する」のチェックを外すだけにしてください。記録が残り、復帰したときにすぐ戻せます。 削除すると書いた紹介文ごと消えます。

あゆみ

年表です。記念回やコラボなどの特別イベントを載せます。通常回は載せません。

  • 年：2026 のように数字で入れます。同じ年のものは自動でまとまります。
  • 日付：「10月25日」のように日本語で書きます。
  • 強調表示：その行を目立たせます。第100回のような特別な回に使います。
  • 予告：まだ先の予定に「予告」の札を付けます。

コラボ

企業や公式アカウントとの実績です。ここは取材や依頼の入口になるので、正確に書いてください。

クレジット

使わせてもらっている素材の表記です。フッターに出ます。

5. 保存と反映

  1. 編集したら、画面右上の「保存してデプロイ」を押す
  2. 「保存しました」と出たら成功です
  3. 1〜2分待つとサイトに反映されます

すぐに変わらなくても慌てないでください。反映には少し時間がかかります。 それでも変わらないときは、サイトのページで Ctrl + Shift + R を押してください（古い表示が残っているだけです）。

保存はいま開いている種別だけが対象です。 スタッフとあゆみの両方を直したなら、それぞれの画面で1回ずつ保存してください。

6. 困ったとき

トークンが無効か期限切れですトークンの期限が切れています。手順2で作り直し、ログアウトしてから入れ直してください。
他の人が先に更新しています別の人が同時に編集して保存しました。上書きせずに止めています。ページを再読み込みして、編集をやり直してください。
ファイルが見つかりませんデータファイルの名前が変わったか、消えています。触らずに相談してください。
保存したのにサイトが変わらない1〜2分待つ。それでも駄目なら Ctrl + Shift + R。
「グループに参加する」が押せない開催情報の「VRChatグループURL」が空です。URLを入れて保存してください。
編集内容を消してしまった保存前ならページを再読み込みすれば元に戻ります。保存後でも、GitHubに履歴が残っているので復元できます。慌てず相談してください。

やらないほうがいいこと

  • トークンを他人に渡す、画面に映したまま配信する
  • スタッフを「削除」する（非表示にするだけで足ります）
  • データファイルをGitHub上で直接編集する（この画面から編集すれば安全です）

7. 引き継ぎについて

このサイトは GitHub の Organization（組織アカウント）の下に置いてあります。 運営が代わるときは、その Organization のオーナー権限を渡せば、 サイトのURL・データ・この編集画面がまとめて引き継がれます。

個人のアカウントにぶら下げていないのは、そのためです。 引き継いだ人はこのマニュアルをそのまま読めば運用を続けられます。
